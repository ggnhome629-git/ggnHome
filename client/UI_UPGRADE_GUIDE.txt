PART 1: AFFILIATE vs NORMAL PROPERTIES OVERVIEW
================================================================================

AFFILIATE PROPERTIES (Sourced from NoBroker/99acres):
- Have sourcePortal field set to "nobroker" or "99acres"
- Have sourceUrl pointing to external listing
- Show badge: "Sourced from [portal]" with external link icon
- NO contact forms, NO enquiry, NO scheduling
- Primary CTA: "View on NoBroker/99acres" (external link)
- Secondary CTAs: Share, Save
- Hide: Contact card, callback dialog, schedule visit, enquiry form

NORMAL PROPERTIES (Own database):
- No sourcePortal or sourceUrl fields
- Full contact capabilities: phone, WhatsApp, email, messaging
- Can schedule site visits
- Can send enquiries and receive callbacks
- Commission can be set by owner/agent
- Primary CTAs: Schedule visit, Enquire, Request callback
- Show: Agent/owner contact card, verification badges, all interaction forms
